# Cycle Tracker

A lightweight menstrual cycle tracking web app built with vanilla HTML, CSS and JavaScript.

## Features

- Calendar-based cycle tracking
- Cycle day calculation
- Fertility window logic
- Basal Body Temperature (BBT) graph
- Coverline visualization
- Bleeding tracking
- Cervical discharge tracking
- LocalStorage data persistence

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- SVG (for chart rendering)
- LocalStorage

## Project Structure

```bash
index.html
styles.css
app.js
```
